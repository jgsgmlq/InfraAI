# /init - 项目初始化

当用户输入 `/init` 或启动新会话时，执行以下初始化流程。

**执行原则**：先集中运行所有脚本检查，再集中输出文本展示，提升用户体验。

---

## 阶段一：静默检查

按顺序运行以下命令，捕获输出供后续使用：

### 1.1 健康检查

```bash
python scripts/audit_all.py --quiet
```

记录退出码（0=健康，非0=有问题）。

### 1.2 获取最近提交

```bash
git log -1 --oneline
```

### 1.3 获取工具列表

```bash
python scripts/list_tools.py --compact
```

如果 `--compact` 不可用，使用默认输出并精简展示。

### 1.4 获取技能列表

```bash
python scripts/list_skills.py --compact
```

如果 `--compact` 不可用，使用默认输出并精简展示。

## 注意事项

- 如果 `--compact` 选项不可用，使用原有输出并精简展示
- 外部插件能力明确标注来源（superpowers 插件）
- 保持输出简洁，避免信息过载
- 用户只需用自然语言表达意图，无需记忆命令

**关于工作模式：**
- AI 默认处于"项目开发模式"，会在项目子目录中工作
- 只有在用户明确说"修改 SDK"、"扩展框架"等关键词时，才进入"SDK 开发模式"
- 如果不确定用户意图，AI 会先询问用户
- 框架层（sdks/、scripts/、.claude/、docs/）是稳定的，不会随意修改
