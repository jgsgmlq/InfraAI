# /init - 项目初始化

当用户输入 `/init` 或启动新会话时，执行以下初始化流程。

**执行原则**：先集中运行所有脚本检查（Bash 输出集中），再集中输出文本展示，提升用户体验。

---

## 阶段一：静默检查（集中 Bash 执行）

按顺序运行以下脚本，**捕获输出但不立即展示**，将结果存储在内存中供后续使用：

### 1.1 健康检查

运行：
```bash
python scripts/audit_registry.py --quiet
```

记录退出码：
- 退出码 0：健康
- 退出码非 0：有问题

### 1.2 获取工具列表

运行：
```bash
python scripts/list_tools.py
```

解析输出，提取工具名称列表和数量。

### 1.3 获取技能列表

运行：
```bash
python scripts/list_skills.py
```

解析输出，按来源分类提取技能名称。

---

## 自动执行配置（可选）

如需每次启动时自动执行初始化，可在 CLAUDE.md 中添加：

```markdown
## 启动时

运行 `/init` 完成项目初始化。
```

或配置 Claude Code hooks（参考 `.claude/settings.json`）。
